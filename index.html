Planning assumptions

Assumes on-time return and successful calibration. New certificate validity starts on return (default: 6 months; adjust to the actual certificate). An expiry date is the last usable day. Instruments with missing dates, missing serials, or unavailable conditions are excluded. Instruments already away need a confirmed return date before inclusion. This simulation does not change the register.

Earliest expiry goes first. The first rotation may start early to stagger simultaneous expiries; later rotations aim to leave 3 months before expiry. Valid instruments leave only when remaining coverage meets the target until return. Expired instruments are proposed for immediate calibration. This is a suggested rotation, not an optimized or guaranteed plan.
